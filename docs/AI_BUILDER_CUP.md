# AI Builder Cup 2026 submission notes

Checked against the event's [overview](https://aibuildercup.com/) and [themes and judging page](https://aibuildercup.com/themes.html) on 26 September 2026.

- **Prototype submission deadline:** 18 October 2026. The current repo roadmap targets 15 October, leaving three days for submission checks.
- **Required prototype:** a functional solution using a Google AI model such as Gemini or Gemma, deployed on Google Cloud through Cloud Run or Firebase.
- **Submission materials:** a proposal deck exported to PDF and a public three-minute demo video or public Google Drive link.
- **Relevant theme:** Future of Work & Enterprise Productivity fits Decision Radar's project decision and evidence workflow.
- **Judging weights:** technical merit and Gen AI implementation 40%; problem alignment and impact 25%; innovation and creativity 25%; user experience and solution design 10%.

For the demo, prioritize a reliable end-to-end path from source update to quote-backed contradiction, interactive downstream impact, and human review. The synthetic fixture provides a fallback when live Workspace integration is unavailable. This is a project implementation inference from the judging criteria and the MVP design, not an additional event rule.
